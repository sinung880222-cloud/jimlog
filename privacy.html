  • 운영자를 포함해 누구도 내 데이터를 볼 수 없어요.

1. 운영자

짐로그(이하 "앱")는 개인이 운영하는 나들이 짐 정리 웹앱이에요.

주소: https://sinung880222-cloud.github.io/jimlog/

2. 저장하는 정보와 저장 위치

앱 데이터 — 장비 이름·분류·무게·가격·크기·구매일, 식량·소모품, 다녀온 기록(날짜·이름·일정·메모·사용한 장비), 장소(이름·좌표·주소).

  • 내 기기: 사용 중인 브라우저의 저장 공간(localStorage)에 저장돼요. 기기 밖으로 전송되지 않아요.
  • 내 구글 드라이브 (구글 로그인을 선택한 경우만): 내 드라이브 안의 짐로그 전용 숨김 폴더(앱 데이터 폴더)에 저장돼요. 이 폴더는 짐로그만 읽고 쓸 수 있고, 드라이브의 다른 파일에는 접근하지 않아요.

구글 계정 정보 (구글 로그인을 선택한 경우만) — 이메일 주소와 이름. 로그인 상태를 화면에 표시하는 데만 쓰이며, 내 기기에만 저장돼요.

장소(이름·좌표·주소)도 앱 데이터의 일부로, 내 기기와 (구글 로그인을 선택한 경우) 내 구글 드라이브에만 저장돼요. 운영자에게 전송되지 않아요.

위치 권한 — 현재 위치를 쓰는 [📍 지금 위치] 버튼을 누를 때만 브라우저가 위치 권한을 물어요. 앱을 열거나 쓰는 동안 위치를 몰래 가져오지 않으며, 가져온 위치는 내가 저장한 장소에만 쓰여요.

운영자는 별도의 서버나 데이터베이스를 운영하지 않으므로, 위 정보는 운영자에게 전송되거나 보관되지 않아요.

3. 구글 계정 및 Google API 사용

구글 로그인은 선택 사항이에요. 로그인하지 않아도 모든 기능을 쓸 수 있어요. 로그인하면 여러 기기에서 같은 데이터를 쓰고, 기기를 바꾸거나 데이터를 잃었을 때 복구할 수 있어요.

앱이 요청하는 권한은 다음뿐이에요.

  • drive.appdata — 짐로그 전용 숨김 폴더의 파일 읽기·쓰기
  • openid, email, profile — 로그인한 계정 표시

짐로그가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수해요.

Google API로 받은 정보는 앱 기능 제공에만 쓰며, 광고·판매·제3자 제공·AI 학습에 사용하지 않아요.

4. 제3자 제공 및 외부 서비스

  • 개인정보를 제3자에게 제공하거나 판매하지 않아요.
  • 앱은 GitHub Pages에서 제공되며, 접속 시 GitHub가 일반적인 접속 기록(IP 주소 등)을 처리할 수 있어요. 이는 GitHub 개인정보처리방침을 따라요.
  • 장소를 고르거나 다녀온 곳 지도를 볼 때 네이버 지도 서비스(네이버클라우드)를 이용해요. 지도를 열면 브라우저가 네이버 서버에서 지도 데이터를 받고, 주소 검색·핀 위치의 주소 변환을 위해 입력한 주소나 핀 좌표가 네이버 지도 서비스로 전달될 수 있어요. 이 과정은 네이버가 처리하며 네이버 개인정보처리방침을 따라요. 지도를 열지 않으면 전달되지 않아요.
  • 구글 로그인 시 로그인 과정은 Google이 처리하며 Google 개인정보처리방침을 따라요.
  • 현재 광고, 방문 분석 도구, 추적 쿠키를 쓰지 않아요. 이후 도입하면 이 문서를 먼저 고치고 앱에서 알려드릴게요.

5. 보관 기간과 삭제 방법

데이터는 직접 지우기 전까지 보관돼요. 언제든 아래 방법으로 지울 수 있어요.

  • 내 기기 데이터: 앱 메뉴 → 전체 비우기, 또는 브라우저의 사이트 데이터 삭제.
  • 구글 드라이브 데이터: 앱 메뉴 → 드라이브의 짐로그 데이터 삭제. 또는 구글 드라이브 → 설정 → 앱 관리 → 짐로그 → 숨겨진 앱 데이터 삭제.
  • 구글 계정 연결 해제: 앱 메뉴 → 로그아웃, 또는 구글 계정 → 보안 → 타사 앱 및 서비스에서 짐로그 연결 삭제.

6. 이용자의 권리

이용자는 언제든 자신의 데이터를 확인·수정·삭제하고, 백업 파일(JSON)로 내보낼 수 있어요. 데이터가 운영자에게 없기 때문에 이 모든 작업은 앱 안에서 직접 할 수 있어요.
